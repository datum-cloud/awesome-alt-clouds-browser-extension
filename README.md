# Alt Cloud Browser Extension

Browser extension for [Alt Cloud](https://www.alt-cloud.org/) — check if any site you're browsing is in the Alt Cloud directory and suggest new listings with one click.

## Browser support

| Directory | Target |
|-----------|--------|
| [`chrome/`](./chrome/) | Chrome / Chromium (Manifest V3) — **active** |
| `firefox/` | Firefox (WebExtensions) — planned |
| `edge/`    | Edge — same package as Chrome, planned |

## What it does

On every page load the extension checks the tab's hostname against the Alt Cloud directory and shows one of five states:

| State | Icon | Meaning |
|-------|------|---------|
| 🟢 Listed (3/3) | Green + ✓ | Meets all 3 transparency criteria |
| 🟡 Listed (2/3) | Amber + ! | Meets 2 of 3 — popup shows what's missing |
| 👀 Future Cloud | Blue | On the watch list |
| ➕ Not listed | Grey + + | One-click suggest flow |
| ⬜ Unchecked | Dim grey | Internal page, known platform, or dismissed |

## Quick start (Chrome)

1. Clone this repo.
2. Open Chrome → `chrome://extensions` → enable **Developer mode**.
3. Click **Load unpacked** → select the `chrome/` folder.

See [`chrome/README.md`](./chrome/README.md) for full details including privacy statement, matching logic, and the suggestion flow.

## Directory listing data

The extension fetches `https://www.alt-cloud.org/clouds.json` — the JSON artifact generated by the [awesome-alt-clouds](https://github.com/datum-cloud/awesome-alt-clouds) CI pipeline from `README.md`. Cached for 24 hours; manually refreshable from the popup footer.
