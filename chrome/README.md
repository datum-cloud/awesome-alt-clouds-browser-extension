# Alt Cloud Checker — Chrome Extension

A Manifest V3 Chrome extension. On any page it tells you one of five things about the site:

| State | Badge | Meaning |
|-------|-------|---------|
| 🟢 Listed (3/3) | ✓ green | On Alt Cloud, meets all 3 criteria |
| 🟡 Listed (2/3) | ! amber | On Alt Cloud, meets 2 of 3 — popup shows what's missing |
| 🔵 Future Cloud | ~ blue | On the watch list — promising but not yet meeting the bar |
| ⚫ Not listed | ＋ grey | One-click path to suggest it |
| ⚪ Unchecked | - grey | Internal page or known platform (GitHub, Twitter, etc.) |

The toolbar icon is the Alt Cloud logo with a coloured dot in the bottom-right corner indicating the current state.

## Installation (developer / beta)

1. Clone this repository.
2. Open Chrome → `chrome://extensions` → enable **Developer mode**.
3. Click **Load unpacked** → select the `chrome/` folder.
4. The Alt Cloud icon appears in your toolbar. Pin it via the puzzle-piece menu if needed.

## How it works

1. On every page load the service worker checks the tab's hostname against the cached directory index (`clouds.json` from `alt-cloud.org`).
2. Matching is registrable-domain based — `docs.example.com` matches an entry for `example.com`.
3. Platform sites (GitHub, Twitter, LinkedIn, etc.) are always shown as unchecked/grey; the extension does not badge on every page.

## Suggest flow

Clicking **Suggest this site** opens a prefilled GitHub issue matching the format expected by the `evaluate-submission.yml` workflow — URL, timestamp, and a standard notes field. The GitHub Action evaluates the service and assigns name, description, and category automatically. The user reviews and submits the form manually.

## Report / correction flow

From any listed state (green, amber, Future Cloud), a secondary action opens a prefilled GitHub issue for corrections — e.g. "they removed their pricing page" or "they've graduated from Future Cloud."

## Privacy

| What | Detail |
|------|--------|
| Page content read | `document.title`, `<meta og:*>` tags, favicon URL, and `location.hostname`. Nothing else. |
| Data sent off-device | **None by default.** The only outbound request is a daily fetch of `clouds.json` from `alt-cloud.org`. |
| Suggestion flow | Opens a prefilled GitHub issue URL in a new tab. The user reviews and submits manually — nothing is posted automatically. |
| Telemetry | None. No analytics, no remote config, no kill switch. |

This privacy posture is intentional. Alt Cloud is built on a transparency thesis — the extension should be congruent with that.

## The 3 criteria

Alt Cloud lists services that meet at least 2 of 3 public criteria:

1. **Transparent public pricing** — prices visible without signing up or contacting sales
2. **Usage-based self-service** — can sign up and start using the service without a sales call
3. **Production indicators** — public SLA commitment, status page, or uptime tracker

The popup shows which criteria each listed service meets. For services where the per-criterion breakdown isn't tracked (2/3 entries), the extension says so explicitly — it never rounds up.

## Data dependency

The extension fetches `https://www.alt-cloud.org/clouds.json` — the same JSON generated by the repo's CI pipeline. It caches this for 24 hours. A manual **Refresh** button is in the popup footer.

Current data schema used: `name`, `url`, `description`, `score`, `categories`, `dateAdded`.
The extension derives `domain`, `tier`, `status`, `criteria`, and `anchor` at runtime.
